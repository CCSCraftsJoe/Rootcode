Rootcode 1.0

Rootcode is an open visual writing system created by Joe Culver / Culver Sculpture for Roots & Signals. It maps Latin A–Z to 26 geometric glyphs. Words are vertical stacks read bottom-to-top. Interior nodes are filled; shared terminal nodes are hollow.

The canonical machine-readable definition is data/rootcode-1.0.json. Specification and assets are CC BY 4.0; reference code is MIT.
